# NursingReviewerIGuess

This repository currently holds an evidence-based product discovery record. It is research only: there is no application code yet.

**Status:** Phase 2 (gap analysis). The active candidate is a reviewer app for nursing students.

## Map of `docs/`

- `STATUS.md` — current state, decisions and next actions (start here)
- `decisions/` — decision log and phase gates
- `research/` — competitive landscape, source register, evidence ledger, interview kit
- `templates/` — interview, profile, experiment and gate templates
- `claude/`, `engineering/` — working agreements and guardrails
- `PROJECT_CHARTER.md`, `ROADMAP.md`, `PROJECT_INVENTORY.md` — scope and plan

## Method

Source-backed research with verification checks: every material claim cites a registered source and an evidence status. The work is run with Claude (strategy) and Claude Code (execution).
