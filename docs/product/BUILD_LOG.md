**Decisions made alone (owner to review)**
1. ts-fsrs v6 configured as `version: 'FSRS-6'` (ADR says FSRS-6; the library default is FSRS-7), `enableShortTerm: false` (whole-day intervals for a once-a-day app; "Again" returns tomorrow, not in 1 minute), `enableFuzz: false`, desired retention 0.9.
2. "Scheduled backward from the exam date" = (a) new items per day = max(10, ceil(unseen ÷ days left)); no exam date → spread over 7 days; (b) any next-review date past the exam is pulled back to the day before the exam.
3. Scheduler state is stored on the item (not re-derived from `reviews` as ADR-001 §5 sketched); the review log is still kept. Recorded in ADR-002 §2.
4. "Due today" = due on or before the end of the local day.
5. Navigation is in-memory (no URL routes); launch always opens Today. Simpler; the Android back button will leave the app.
6. Parser: a numbered line always starts a new block, so a wrapped rationale line beginning "2. …" becomes a (reported) broken block. Blocks with errors are listed in the preview and not saved; valid blocks are saved.
7. `lastExportAt` is device-local: excluded from backups; set to the backup's export time on restore.
8. Import confirmation: restoring a backup always asks "Replace my data with this backup".
