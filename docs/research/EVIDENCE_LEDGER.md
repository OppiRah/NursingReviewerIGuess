## Questions that can kill ideas

- Is the pain recurring and costly enough to change tools?
- Can the intended buyer personally authorize a purchase?
- Does any low-cost/free alternative already solve it?
- Is the user reachable without a large marketing budget?
- Does a product require regulated/private data with disproportionate support cost?
- Does the value collapse if AI accuracy is only average?
- Would a single incumbent release erase the differentiation?

Never write 'validated' based solely on an online complaint. Validation requires targeted behavioral evidence, ideally interviews or pilots with attributable customer contexts and explicit consent.
